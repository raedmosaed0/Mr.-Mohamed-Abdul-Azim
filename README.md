## 📖 About the Project

The **Mr. Mohamed Abdul Azim Website** is an educational landing page designed to present a Biology and Science teacher's experience, teaching approach, and available learning services.

The website provides students with an overview of the teacher's background, educational services, and contact channels through an accessible and user-friendly interface.

## ✨ Key Features

- 🎓 **Professional Introduction** — Showcases the teacher's profile and teaching experience.
- 📊 **Experience Statistics** — Highlights years of experience and student reach.
- 📚 **Educational Services** — Presents Science lessons, Biology sessions, and exam preparation.
- 📱 **Direct Communication** — Provides access to contact details and social media platforms.
- 📱 **Responsive Design** — Adapts to desktop, tablet, and mobile screens.
- ⚡ **Interactive Navigation** — Includes smooth scrolling and active section navigation.
- ☰ **Mobile Navigation** — Provides an accessible menu for smaller screens.

## 🗂️ Website Sections

- **Home** — Main introduction and landing section.
- **About Me** — Teaching background, experience, and educational approach.
- **My Services** — Science lessons, Biology explanations, and exam preparation.
- **Contact Me** — Contact details and social media links.
